# إذاعات القرآن الكريم

صفحة ويب بسيطة للاستماع إلى إذاعات القرآن الكريم، مع قائمة إذاعات وبحث وبث مباشر.

## المميزات

- قائمة إذاعات تضم قراء وتفسير وأذكار وترجمات لمعاني القرآن وفتاوى.
- بحث سريع بالاسم أو التصنيف.
- مشغّل صوت واحد: تشغيل وإيقاف من بطاقة الإذاعة.
- تصميم يدعم العربية (RTL) ويعمل على الجوال والكمبيوتر.
- ملف واحد `index.html` بدون مكتبات أو خادم.

## التشغيل

افتح `index.html` في المتصفح مباشرة، أو انشره على GitHub Pages:

1. من **Settings** ثم **Pages**.
2. اختر الفرع `main` والمجلد الرئيسي (root)، ثم **Save**.

## إضافة إذاعة

القائمة موجودة داخل `index.html` في المصفوفة `Stations`. أضف سطرًا بهذا الشكل:

```js
["اسم الإذاعة", "رابط_البث_أو_الاسم_المختصر", "التصنيف"],
```

إذا كتبت اسمًا مختصرًا فقط (بدون `http`) يُضاف قبله `https://qurango.net/radio/` تلقائيًا.

## ملاحظات

- بعض الروابط تبدأ بـ`http://`، وقد يمنعها المتصفح على موقع `https`.
- إذا توقفت إذاعة عن العمل فالرابط عند مزوّد البث هو السبب غالبًا.
- روابط البث من موقع [qurango.net](https://qurango.net) ومزوّدين آخرين، وقائمة الإذاعات أصلها Gist على GitHub.

نسأل الله القبول والنفع.
